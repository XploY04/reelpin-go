# Active plans

Work that is scoped but not finished. One file per piece of work, named for the
work and not for who is doing it.

A plan is worth writing when the work is large enough that someone else would
need to be told about it, or when the reasoning behind the order matters. It is
not worth writing for a change that fits in one pull request description.

Move the file to `../completed/` when the work ships. Keep it: the reasoning
outlives the work, and the next person doing something similar starts from it
rather than from nothing.

Files matching `*.local.md` here are gitignored, for whoever is holding the pen.
