# Completed plans

What shipped, and why it was done in the order it was done.

These are kept rather than deleted because the reasoning is the useful part. A
plan explaining why enqueueing had to land before the pipeline is worth more
six months later than the checklist it contained.

Do not edit a completed plan to match what actually happened. If the work
diverged from the plan, that divergence is the most interesting thing in the
file: add a short note at the end saying what changed and why.
